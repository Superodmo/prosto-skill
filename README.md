# prosto — понятный русский для ответов агента

Скилл для Claude Code и совместимых агентов. Он переписывает ответ так, чтобы человек понял его с первого прочтения.

Что это значит на деле: короткие предложения, без канцелярита и метафор, число вместо «много», один вопрос в конце.

Подход взят из ASD-STE100 — стандарта упрощённого технического английского для авиационных руководств. Правила английского заменены русскими: канцелярит, отглагольные существительные, цепочки существительных, причастные обороты.

## Установка

Положить папку `prosto` в каталог скиллов:

- глобально, для всех проектов — `~/.claude/skills/prosto/`
- только для одного проекта — `<проект>/.claude/skills/prosto/`

Нужен Python 3.9 или новее — только ради линтера. Сторонние библиотеки не нужны.

## Как пользоваться

Скилл срабатывает сам, когда человек пишет «не понял», «упрости», «разложи», «объясни проще», «структурируй». Можно позвать руками: `/prosto`.

По умолчанию агент отдаёт только переписанный текст. Если попросить «покажи, что поменял» — выведет таблицу: правило, было, стало.

## Линтер

```
python scripts/prosto-lint.py текст.md
cat текст.md | python scripts/prosto-lint.py
python scripts/prosto-lint.py текст.md --json
python scripts/prosto-lint.py --rules
python scripts/prosto-lint.py --selftest
```

Список правил, строгость и пороги печатает сам скрипт: `--rules`. Два уровня. Жёсткие находки роняют проверку, советы — нет.

Коды выхода: 0 — чисто, 1 — жёстких находок больше, чем разрешает `--baseline`, 2 — ошибка в команде или нечитаемый файл.

Смягчения — «возможно», «похоже», «предполагаю» — не помечаются никогда: это содержание, а не стиль.

## Что исключается из проверки

Шапка файла, блоки кода, строки через `>` и всё между метками:

```
<!-- prosto-lint: off -->
текст с нарочными примерами плохих слов
<!-- prosto-lint: on -->
```

Других исключений нет. В кавычках, в таблице и в списке правила работают.

## Чего скилл не делает

- Не меняет смысл и не превращает «возможно» в «точно».
- Не добавляет фактов, которых не было в исходном тексте.
- Не правит письма, посты и презентации — он про разговор, а не про публикацию.
- Не знает морфологии русского. Там, где правило держится на окончаниях слов, оно помечено как совет: страдательный залог, причастия, цепочки существительных, отглагольные.

## Состав

```
prosto/
├── SKILL.md                 правила для агента
├── README.md                этот файл
└── scripts/prosto-lint.py   линтер, только стандартная библиотека
```
